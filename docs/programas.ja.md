# コアのプログラム

75 のプログラムと 600 のプリセット。各プログラムは `programas/` のテキストファイルで、プリセットは `presets/banco.toml` にあります。プログラム名とプリセット名はスペイン語です。
サイクル数は RTL の上限で、1 サンプルあたり 2,048（`model/sofifi/domain/coste.py`）。メモリーは 43,008 ワードです。
