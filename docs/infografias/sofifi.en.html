Why choose SOFIFI?

A pedal you can read, change and test

A commercial pedal is a closed box. In SOFIFI, each bit of the sound has a readable source and a test that compares it.

In simulation, the RTL gives the same output as the model, bit by bit, in all 86 programs and in the 18 chains that fit. On the board, 77 of 77 match: 68 programs and 9 chains (MED-17).

How it sounds

An effect is a program, not a circuit

The core is fixed. Only the microcode that it runs changes. A new preset does not need a change to the RTL (ADR 0006). Two effects at the same time are a chain: the composer joins two programs into one (ADR 0013).

Input

Guitar to the I2S ADC (PCM1808)

Core

2,048 cycles per sample. Pipelined: it waits only when an instruction depends on another (ADR 0014).

Limiter

Fixed in RTL. No program can bypass it.

Output

I2S DAC (PCM5102A)

The microSD will keep the program bank (Phase 08, in progress). It is not the delay memory, because it has write peaks of 250 ms (ADR 0004). The audio lives in the FPGA BSRAM: 43,008 words, approximately 0.88 s. The looper and the granular use 32,768 with absolute addresses: a loop does not move away (ADR 0009).

Why trust it

The model commands. The RTL obeys.

A Python model defines each bit of the output. The RTL must match it sample by sample, with zero tolerance (ADR 0003).

Tested primitives

The tour

13 phases. 8 closed. The missing parts come last.

Up to Phase 08, the board and the microSD are sufficient. Phase 08 already has the bank, the SPI reader and the loader, tested in simulation. The test with a real card is missing. The hardware that is not available today waits for phases 09 to 12.
