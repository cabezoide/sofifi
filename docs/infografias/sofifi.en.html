Why choose SOFIFI?

A pedal you can read, change and test

A commercial pedal is a closed box. In SOFIFI, each bit of the sound has a readable source and a test that compares it.

Bits of difference

In simulation, the RTL gives the same output as the model, bit by bit, in all 43 programs. On the board, the plate matches in 9 of 9 captures (MED-13).

Effects as text

Reverbs, delays, modulation, pitch, dynamics, filters and texture, with 344 presets. Each effect is a .sasm file of 25 to 160 instructions. A new effect does not touch the hardware.

How it sounds

An effect is a program, not a circuit

The core is fixed. Only the microcode that it runs changes. A new preset does not need a change to the RTL (ADR 0006).

Input

Guitar to the I2S ADC (PCM1808)

Core

2,048 instructions per sample, 48-bit accumulator

Limiter

Fixed in RTL. No program can bypass it.

Output

I2S DAC (PCM5102A)

The microSD keeps the programs. It is not the delay memory, because it has write peaks of 250 ms (ADR 0004). The audio lives in the FPGA BSRAM: 43,008 words, approximately 0.88 s.

Why trust it

The model commands. The RTL obeys.

A Python model defines each bit of the output. The RTL must match it sample by sample, with zero tolerance (ADR 0003).

10 hard gates

They run before each push. If one fails, the push does not go out (ADR 0001).

Second pass

Each PR gets an optimization review with resource ratchets (ADR 0010).

Tested primitives

DSP 27×18, 42 BSRAM blocks and a 100 MHz PLL, verified on the board with Yosys, nextpnr and apicula (MED-06 to MED-08).
