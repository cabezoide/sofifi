声音从何而来

效果是程序，不是电路

核心是固定的。变化的只是它执行的微码。新增预设无需修改 RTL（ADR 0006）。同时运行两个效果就是一条链：组合器把两个程序合成一个（ADR 0013）。

输入

吉他接入 I2S ADC（PCM1808）

核心

每个采样 2,048 个周期。流水线：只在指令相互依赖时等待（ADR 0014）。

限幅器

固化在 RTL 中。任何程序都无法绕过。

输出

I2S DAC（PCM5102A）

microSD 将存储程序库（阶段 08，进行中）。它不用作延迟存储器，因为它有 250 ms 的写入峰值（ADR 0004）。音频存放在 FPGA 的 BSRAM 中：43,008 字，约 0.88 s。循环器和颗粒合成使用其中 32,768 字，采用绝对地址：循环不会漂移（ADR 0009）。

为什么可信

模型发令，RTL 服从。

Python 模型定义输出的每一位。RTL 必须逐个采样与之一致，零容差（ADR 0003）。

# 50 / 50 与模型相同（MED-16）
50 / 50个程序和链在 100 MHz 的芯片上与模型逐位相同，测量时使用阶段 07 的多周期内核（MED-16）。
1.6×流水线核心平均减少的周期倍数。hall 降到 2,048 中的 863 个（ADR 0014）。
125 MHz流水线核心无错误（3 / 3）；133.3 MHz 为 2 / 2。工作频率为 100 MHz（MED-14）。

11 道硬检查门

每次 push 前运行。只要有一道失败，push 就不会发出（ADR 0001）。

第二轮

每个 PR 都要通过一次带资源棘轮的优化审查（ADR 0010）。

原语已验证

DSP 27×18、42 个 BSRAM 块和 100 MHz PLL，已在开发板上用 Yosys、nextpnr 和 apicula 验证（MED-06 至 MED-08）。

巡演路线

13 个阶段。8 个已完成。缺的放在最后。
