The encore

Five features that no pedal combines

No source in this review names a commercial ambient pedal on an FPGA INF. Each feature comes from a decision that the project already made.

Open programs with a bit-exact model

You write an effect in assembly and listen to it on the PC. It sounds the same on the pedal, bit for bit (ADR 0003, ADR 0006).

Zero CPU crackles

Each program has a fixed number of cycles. MOD Dwarf users report crackles when the CPU is at 100 % V.

Presets you can read

Text files, with the full state. You can put them under version control and share them. sofifi banco already writes the microSD bank, with CRC (phase 08).

The second layer, in view

The OLED shows the function of each knob, in Spanish, English, Chinese and Japanese. Users often complain about functions without labels ?.

FV-1 compatible

The assembler already uses a SpinASM-like syntax. A translator would bring in its library (plan). An open FV-1 emulator came out in 2026 V.
